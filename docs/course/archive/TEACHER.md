# Преподавателю

## Организация репозитория

Материалы опубликованы в одном репозитории [CS-AI-MMCS](https://github.com/Ekaterina0801/CS-AI-MMCS): pmi/ и fiit/ — два направления. Студент делает fork всего репозитория, затем работает в своей папке. Создавать два дополнительных репозитория не требуется.

- Практики 01–02 оформлены; 03–14 остаются невыданными заготовками по планам.
- Сроки назначает преподаватель. Сервис проверки пока не подключён.
- Для приватных решений выдавайте отдельные закрытые копии; публичные fork видны всем.
- Коллегам выдавайте права, необходимые для редактирования заданий. Персональные списки и оценки не размещайте в публичном репозитории.
- Первый код намеренно не завершён; открытые тесты должны находить ошибки до исправления.

## Обновление курса

Клонируйте преподавательский репозиторий, создайте рабочую ветку, внесите изменения и проверьте diff. Перед публикацией используйте pull request для проверки условий, примеров и тестов. Для нового задания следуйте порядку ниже.

## Публикация следующей практики

Уточните условие, входы и выходы, обязательные файлы, данные, примеры, зависимости и критерии. Добавьте тесты и проверьте их на правильном и типично ошибочных решениях. Затем обновите соответствующую запись course.json: status=published, version, required_files, grading и deadline. Согласованно обновите таблицу README.md.

Не выдавайте студентам draft-практики. Не объявляйте ручную проверку автоматической. Для графиков проверяйте вычисленные данные и создание артефактов автоматически, а подписи, выбор графика и интерпретацию — по рубрике.

## Эталонные решения и скрытые тесты

Храните в отдельном закрытом репозитории, никогда не в ветке публичного учебного репозитория. Удалённый из последнего коммита файл может оставаться в истории. Этот комплект содержит только открытые материалы.

## Примечание о плане

В исходных планах 16 тем. По договорённости оформлено 14 практик; темы 15–16 остаются вне комплекта. Практика 02 ФИИТ рассчитана исходным планом на две пары.
