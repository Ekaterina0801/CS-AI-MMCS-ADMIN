## Очистка данных

Определите функцию `clean`, которая принимает исходную таблицу и возвращает очищенную:

```python
def clean(df: pd.DataFrame) -> pd.DataFrame:
    out = df.copy()
    ...
    return out
```

Если функции нет, сервис возьмёт переменную `clean_df`, `df_clean` или `df` — но с функцией
проверка точнее и вам самим удобнее. Результат сравнивается с эталоном преподавателя:
колонки, типы, число строк и значения ячеек с допуском. О расхождениях сервис сообщает
конкретно: колонка, доля несовпавших значений и пример «ожидалось / получено».

Отдельно проверяется, **как** вы чистили:

| Что смотрит сервис | Как пройти |
|---|---|
| пропуски | заполнить осмысленно или удалить с `subset` |
| дубликаты | `drop_duplicates()` после нормализации значений |
| типы | числа — числами, даты — датами, никаких `object` там, где должно быть число |
| регистр и пробелы в категориях | `.str.strip().str.lower()` |
| выбросы | обработать те колонки, где их доля выше порога |
| потеря строк | нельзя терять больше заданной доли наблюдений |

Голый `dropna()` без `subset` считается ошибкой: он удаляет строку целиком из-за одного
пропуска. `fillna(0)` для цен и оценок отмечается замечанием — ноль искажает статистики.
Цепочечное присваивание `df[a][b] = ...` считается ошибкой: оно меняет копию, а не таблицу.

## Ответы на вопросы

Каждый вопрос практики имеет ключ. Положите ответы в словарь `ANSWERS` или верните их из
функции `answers`:

```python
def answers(df: pd.DataFrame) -> dict:
    return {
        "q_total_revenue": round(float(df["revenue"].sum()), 2),
        "q_top_city": str(df.groupby("city")["revenue"].sum().idxmax()),
    }

ANSWERS = answers(clean_df)
```

Ответы должны **вычисляться из данных**. Словарь, целиком собранный из констант, сервис
распознаёт и не засчитывает: проверяется работа, а не число.

## Графики

Стройте графики как обычно — сервис перехватывает их при `plt.show()`, при `savefig()` и
подбирает фигуры, оставшиеся открытыми в конце работы. Все они сохраняются картинками на странице попытки,
преподавателю не нужно запускать ваш код.

По каждому графику проверяются:

* **тип** — столбчатая, гистограмма, линейный, точечная, круговая, ящик с усами, тепловая карта;
* **заголовок и подписи осей** — график без них нельзя прочитать без кода;
* **легенда**, если серий больше одной;
* **число точек или столбцов**;
* **значения за графиком** — высоты столбцов и точки линии сверяются с эталоном.

```python
by_city = df.groupby("city")["revenue"].sum().sort_index()
fig, ax = plt.subplots(figsize=(8, 4.5))
ax.bar(by_city.index, by_city.values)
ax.set_title("Выручка по городам")
ax.set_xlabel("Город")
ax.set_ylabel("Выручка, руб.")
plt.show()
```

Ожидаемый график сопоставляется с построенным по ключевым словам заголовка и типу —
поэтому заголовок должен отражать содержание, а не быть «График 1».

## Частые причины нулевого балла

| Симптом в разборе | Что произошло |
|---|---|
| «Код студента завершился ошибкой» | решение падает при запуске целиком; проверьте, что оно работает из чистого каталога |
| «Очищенный датасет не найден» | нет ни `clean()`, ни `clean_df`, ни файла с результатом |
| «Ответы записаны константами» | значения в `ANSWERS` не вычисляются из таблицы |
| «Подходящий график не найден» | график не построен или его заголовок не связан с заданием |
| «Значения не совпадают с эталоном» | график построен по неочищенным или неагрегированным данным |
| «Превышено время выполнения» | цикл по строкам вместо векторных операций |
