# Сервис проверки · обзор для преподавателя

<sub>[← Главная](../../README.md)</sub>

Сервис принимает работы студентов, запускает проверки, считает автоматическую часть оценки и собирает всё
для защиты. Адрес сервиса и учётную запись преподавателя выдаёт администратор.

## Роли

| Роль | Что может |
|---|---|
| **Студент** | видит выданные лабораторные, условия и открытые материалы; сдаёт работы; видит разбор своих попыток |
| **Преподаватель** | всё про оценивание: очередь, журнал, защита, совпадения; настраивает лабораторные, тесты, материалы, группы |
| **Администратор** | всё, что преподаватель, плюс пользователи и журнал действий |

## Разделы, которыми вы пользуетесь

| Раздел | Зачем |
|---|---|
| **Обзор** | сколько сдано, средний балл по лабораторным, какие проверки проваливают чаще всего |
| **Очередь проверки** | работы, где автоматика отработала, а защита ещё не выставлена |
| **Журнал оценок** | лучший результат каждого студента по лабораторным; фильтр по группе и году; выгрузка CSV |
| **Все попытки** | история сдач с фильтрами по практике, группе и статусу |
| **Совпадения работ** | похожие работы разных студентов; решение по каждой паре — за вами |
| **Проверить решение** | отправить свою работу, в том числе в черновик — чтобы проверить практику до выдачи |
| **Материалы и лекции** | презентации, практикумы, теория и шпаргалки; у каждого — кому виден |
| **Практики** | условия, тесты, критерии, разбалловка, датасеты, вопросы защиты |
| **Группы** | учебные группы с годом набора; распределение студентов |
| **Справка преподавателю** | эти же инструкции внутри сервиса |

## Как проходит одна лабораторная

1. **Перед выдачей.** Практика — черновик. Отправьте эталон через «Проверить решение»: он должен набрать
   100% автоматической части. Переключите статус на «Выдана студентам».
2. **Во время сдачи.** Студенты отправляют работы; разбор появляется у них через несколько секунд.
   Ваше участие не нужно.
3. **Защита.** Очередь проверки → попытка → вопросы из банка → баллы за ручные критерии →
   «Оценка окончательная».
4. **Итоги.** Журнал оценок по группе → при необходимости выгрузка CSV.
5. **Совпадения.** Раздел «Совпадения работ»: для каждой пары отметьте «списывание», «случайное совпадение»
   или «требует разговора».

## Что видит студент, а что нет

| Видит | Не видит |
|---|---|
| открытые тесты: ввод, ожидаемый и полученный вывод | входы скрытых тестов — только «пройден / не пройден» |
| подсказки при провале | секретные тесты |
| баллы автоматической части и итог после защиты | вопросы защиты и ожидаемые ответы |
| материалы с пометкой «для всех» | материалы «только преподавателям» |
| свою группу и свои попытки | совпадения с другими работами |
