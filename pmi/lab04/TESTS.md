# Тесты · ПМИ · Лабораторная 04

Ровно то, что заведено в сервисе проверки. **Скрытые тесты студенты не видят** — в студенческий репозиторий их не переносить.

Двенадцать вызовов функций из `stats.py` (6 баллов, по 0,5 за тест) и два запуска `main.py`
с журналом на входе (1 балл, по 0,5). Функции вызываются импортом файла студента;
`main.py` запускается как программа, его вывод сравнивается по числам.

## Функции в `stats.py`

| Вызов | Видимость | Ожидаемое значение |
|---|---|---|
| `parse_record("Азов;24.5;2026-07-01")` | открытый | `{"city": "Азов", "temperature": 24.5, "date": "2026-07-01"}` |
| `parse_record("Таганрог;30;2026-07-01")` | открытый | `{"city": "Таганрог", "temperature": 30.0, "date": "2026-07-01"}` |
| `parse_record(" Азов ; -3,5 ; 2026-01-09 ")` | 🔒 **скрытый** | `{"city": "Азов", "temperature": -3.5, "date": "2026-01-09"}` |
| `read_valid(["Азов;24.5;2026-07-01", "мусор", "Азов;25.5;2026-07-02"])` | открытый | `[{"city": "Азов", "temperature": 24.5, "date": "2026-07-01"}, {"city": "Азов", "temperature": 25.5, "date": "2026-07-02"}]` |
| `read_valid(["Азов;24.5;2026-07-01", "", "Ростов;н/д;2026-07-01", "Ростов;;2026-07-02", "Ростов;20;2026-07-03;лишнее"])` | открытый | `[{"city": "Азов", "temperature": 24.5, "date": "2026-07-01"}]` |
| `read_valid([])` | 🔒 **скрытый** | `[]` |
| `read_valid([";24.5;2026-07-01", "Азов;24.5;"])` | 🔒 **скрытый** | `[]` |
| `average_by_city([{"city": "Азов", "temperature": 24.5, "date": "2026-07-01"}, {"city": "Азов", "temperature": 25.5, "date": "2026-07-02"}, {"city": "Таганрог", "temperature": 30.0, "date": "2026-07-01"}])` | открытый | `{"Азов": 25.0, "Таганрог": 30.0}` |
| `average_by_city([{"city": "Ростов", "temperature": -3.0, "date": "2026-01-01"}, {"city": "Ростов", "temperature": 4.0, "date": "2026-01-02"}])` | 🔒 **скрытый** | `{"Ростов": 0.5}` |
| `average_by_city([])` | 🔒 **скрытый** | `{}` |
| `warmest_city([{"city": "Азов", "temperature": 24.5, "date": "2026-07-01"}, {"city": "Таганрог", "temperature": 30.0, "date": "2026-07-01"}])` | открытый | `"Таганрог"` |
| `warmest_city([{"city": "Батайск", "temperature": 20.0, "date": "2026-07-01"}, {"city": "Азов", "temperature": 20.0, "date": "2026-07-01"}])` | 🔒 **скрытый** | `"Азов"` |

## Программа `main.py`

| Тест | Видимость | Ввод | Ожидаемый вывод |
|---|---|---|---|
| отчёт по журналу с одной испорченной строкой | открытый | `Азов;24.5;2026-07-01`<br>`мусор`<br>`Азов;25.5;2026-07-02`<br>`Таганрог;30;2026-07-01` | `3`<br>`1`<br>`30.0` |
| пустые строки не считаются ошибками | 🔒 **скрытый** | `Ростов;н/д;2026-07-01`<br>(пустая строка)<br>`Ростов;20;2026-07-01`<br>`Азов;22;2026-07-01`<br>`Азов;24;2026-07-02` | `3`<br>`1`<br>`23.0` |

## Что ловит каждый скрытый тест

| Тест | Ошибка, которую он находит |
|---|---|
| `parse_record` с пробелами и запятой | поля не очищены `strip`, запятая не принята за десятичную точку |
| `read_valid([])` | функция падает или возвращает не список на пустом входе |
| `read_valid` с пустым городом и пустой датой | проверены количество полей и число, но не пустые поля |
| `average_by_city` с отрицательными | округление или накопление сломано на минусе |
| `average_by_city([])` | нет обработки пустого списка |
| `warmest_city` при равных средних | не задан порядок при равенстве: ответ зависит от порядка словаря |
| `main.py` с пустой строкой | пустая строка посчитана пропущенной |
