## Решения

В каждой задаче завожу отдельные переменные под входные значения, затем вычисляю результат
и печатаю его через f-строку с нужным числом знаков после точки. В задаче 3 количество
читаю через `int`, а цену — через `float`: количество тетрадей дробным быть не может.
В задаче 5 обмен идёт через третью переменную `temp`, иначе исходное значение `a` теряется.
В задаче 6 преобразование к числу не нужно: `input()` уже возвращает строку.

## Объяснения

Собственные примеры подбирала так, чтобы они отличались от условия по существу, а не по
цифрам: округление вниз и вверх, ноль, отрицательные значения, дробные стороны.

Для задачи 5 значения по шагам при вводе 12 и 7: после `temp = a` получаем a = 12, b = 7,
temp = 12; после `a = b` получаем a = 7, b = 7, temp = 12; после `b = temp` получаем
a = 7, b = 12, temp = 12. Именно третья переменная сохраняет исходное значение.

Для задачи 6 сверила пробелы и знаки препинания посимвольно: после «Студент:» один пробел,
после имени точка и пробел, в конце строки точка.
