# Тесты · ПМИ · Лабораторная 05

Ровно то, что заведено в сервисе проверки. **Скрытые тесты студенты не видят** — в студенческий репозиторий их не переносить.

Десять вызовов функций из `logstats.py` (6 баллов, по 0,6 за тест) и два запуска `main.py`
с именем журнала на входе (1 балл, по 0,5).

## Функции в `logstats.py`

| Вызов | Видимость | Ожидаемое значение |
|---|---|---|
| `parse_event("2026-03-01T09:00:11 INFO Сервис запущен")` | открытый | `{"time": "2026-03-01T09:00:11", "level": "INFO", "message": "Сервис запущен"}` |
| `parse_event("2026-03-01T09:03:55 ERROR Не удалось открыть файл data.csv")` | открытый | `{"time": "2026-03-01T09:03:55", "level": "ERROR", "message": "Не удалось открыть файл dat…` |
| `parse_event("  2026-03-01T09:12:30   WARNING   Очередь задач растёт  ")` | 🔒 **скрытый** | `{"time": "2026-03-01T09:12:30", "level": "WARNING", "message": "Очередь задач растёт"}` |
| `count_levels(["2026-03-01T09:00:11 INFO Сервис запущен", "2026-03-01T09:03:55 ERRO…)` | открытый | `{"INFO": 1, "ERROR": 3, "BROKEN": 1, "WARNING": 1}` |
| `count_levels([])` | 🔒 **скрытый** | `{}` |
| `count_levels(["", "   ", "2026-03-01T09:00:11 DEBUG Кэш очищен"])` | 🔒 **скрытый** | `{"DEBUG": 1}` |
| `top_errors(["2026-03-01T09:00:11 INFO Сервис запущен", "2026-03-01T09:03:55 ERRO…, 2)` | открытый | `[["Не удалось открыть файл data.csv", 2], ["Превышено время ожидания", 1]]` |
| `top_errors(["2026-03-01T09:00:11 INFO Сервис запущен", "2026-03-01T09:03:55 ERRO…, 1)` | открытый | `[["Не удалось открыть файл data.csv", 2]]` |
| `top_errors([], 3)` | 🔒 **скрытый** | `[]` |
| `format_report({"ERROR": 2, "INFO": 1}, [["Нет доступа", 2]])` | открытый | `"Отчёт по журналу\n\nERROR: 2\nINFO: 1\n\nЧастые ошибки:\n- Нет доступа — 2\n"` |

## Программа `main.py`

| Тест | Видимость | Ввод | Ожидаемый вывод |
|---|---|---|---|
| Отчёт по полному журналу | открытый | `events.log` | `29`<br>`7`<br>`2` |
| Имя файла берётся из ввода | 🔒 **скрытый** | `events-small.log` | `4`<br>`2`<br>`0` |

Числа взяты из учебных журналов: в `events.log` 29 разобранных строк, 7 уровня `ERROR`
и 2 испорченные; в `events-small.log` — 4, 2 и 0.

## Что ловит каждый скрытый тест

| Тест | Ошибка, которую он находит |
|---|---|
| `parse_event` с лишними пробелами | строка не очищена `strip`, разбор по одному пробелу |
| `count_levels([])` | функция падает на пустом входе |
| `count_levels` с пустыми строками | пустые строки посчитаны как `BROKEN` |
| `top_errors([], 3)` | нет обработки пустого входа |
| `main.py` на `events-small.log` | имя файла зашито в код, а не прочитано из ввода |
