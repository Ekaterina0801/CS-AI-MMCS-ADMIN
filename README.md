## Moodle

Студентам сказано дублировать каждое решение в Moodle. Ссылка на курс вставляется в одном месте —
в разделе «Дублирование в Moodle» главной страницы студенческого репозитория (строка
«**Курс в Moodle:** ссылка появится здесь»); остальные инструкции ссылаются туда.

## Устройство

```
├── pmi/ · fiit/
│   ├── lab01/
│   │   ├── TEACHER.md     ← как проводить и оценивать, типичные ошибки, вопросы защиты с ответами
│   │   ├── TESTS.md       ← все тесты сервиса, включая скрытые
│   │   └── solutions/     ← эталонные решения
│   └── lab02/
│       ├── TEACHER.md
│       └── solutions/     ← образец NOTES.md
├── docs/
│   ├── service/           ← как пользоваться сервисом и заводить лабораторные
│   └── course/            ← устройство репозиториев курса, архив первой версии
└── student/               ← студенческий репозиторий CS-AI-MMCS (подмодуль git)
```

Папка `student/` — не копия, а ссылка на студенческий репозиторий: она всегда показывает ту версию,
на которую её обновили. Обновить до свежей: `git submodule update --remote student`.
При клонировании этого репозитория используйте `git clone --recurse-submodules`.
