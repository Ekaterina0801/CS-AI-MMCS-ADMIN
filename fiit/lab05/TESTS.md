# Тесты · ФИИТ · Лабораторная 05

Ровно то, что заведено в сервисе проверки. **Скрытые тесты студенты не видят** — в студенческий репозиторий их не переносить.

Десять вызовов функций из `tablestats.py` (6 баллов, по 0,6 за тест) и два запуска `main.py`
с именем таблицы на входе (1 балл, по 0,5).

## Функции в `tablestats.py`

| Вызов | Видимость | Ожидаемое значение |
|---|---|---|
| `read_rows(["дата,тип,минуты", "2026-03-01,запуск,1.5", "2026-03-01,ошибка,0.4",…)` | открытый | `[{"дата": "2026-03-01", "тип": "запуск", "минуты": "1.5"}, {"дата": "2026-03-01", "тип": …` |
| `read_rows([])` | 🔒 **скрытый** | `[]` |
| `read_rows(["дата,тип,минуты", "", "  2026-03-01 , запуск , 1.5 "])` | 🔒 **скрытый** | `[{"дата": "2026-03-01", "тип": "запуск", "минуты": "1.5"}]` |
| `count_types([{"дата": "2026-03-01", "тип": "запуск", "минуты": "1.5"}, {"дата": "…)` | открытый | `{"запуск": 1, "ошибка": 2}` |
| `count_types([])` | 🔒 **скрытый** | `{}` |
| `total_minutes([{"тип": "ошибка", "минуты": "0.4"}, {"тип": "ошибка", "минуты": "1"}…, "ошибка")` | открытый | `1.4` |
| `total_minutes([{"тип": "запуск", "минуты": "2"}], "выгрузка")` | 🔒 **скрытый** | `0.0` |
| `total_minutes([{"тип": "ошибка", "минуты": "1,5"}, {"тип": "ошибка", "минуты": "н/д…, "ошибка")` | 🔒 **скрытый** | `1.5` |
| `to_csv({"запуск": 4, "ошибка": 4, "выгрузка": 2})` | открытый | `"тип,количество\nвыгрузка,2\nзапуск,4\nошибка,4\n"` |
| `to_csv({})` | 🔒 **скрытый** | `"тип,количество\n"` |

## Программа `main.py`

| Тест | Видимость | Ввод | Ожидаемый вывод |
|---|---|---|---|
| Сводка по полной таблице | открытый | `events.csv` | `14`<br>`4`<br>`2.5` |
| Имя файла берётся из ввода | 🔒 **скрытый** | `events-small.csv` | `3`<br>`2`<br>`2.0` |

Числа взяты из учебных таблиц: в `events.csv` 14 записей, 4 типа и 2.5 минуты у типа «ошибка»;
в `events-small.csv` — 3, 2 и 2.0.

## Что ловит каждый скрытый тест

| Тест | Ошибка, которую он находит |
|---|---|
| `read_rows([])` | функция падает на пустом входе |
| `read_rows` с пробелами | значения не очищены `strip` |
| `count_types([])` | нет обработки пустого списка |
| `total_minutes` с отсутствующим типом | возвращается не `0.0`, а ошибка или `None` |
| `total_minutes` с `1,5` и `н/д` | запятая не принята за точку, нечисловое значение роняет подсчёт |
| `to_csv({})` | заголовок не выводится для пустой сводки |
| `main.py` на `events-small.csv` | имя файла зашито в код, а не прочитано из ввода |

## Запрет модуля csv

У практики заданы запрещённые конструкции: `import csv` и `from csv import ...`.
Проверка отмечает их как нарушение — разбор таблицы должен быть ручным.
