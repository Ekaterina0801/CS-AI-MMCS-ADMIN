# Тесты · ФИИТ · Лабораторная 04

Ровно то, что заведено в сервисе проверки. **Скрытые тесты студенты не видят** — в студенческий репозиторий их не переносить.

Четырнадцать вызовов функций из `solution.py`, 7 баллов на все: тест весит 0,5 балла.
Проверка импортирует файл студента и вызывает функцию с этими аргументами, результат сравнивается
с ожидаемым (числа — с допуском 1e-6).

| Вызов | Видимость | Ожидаемое значение |
|---|---|---|
| `winner(["Аня", "Боря", "Вика"], [7.0, 9.0, 8.0])` | открытый | `"Боря"` |
| `winner(["Аня", "Боря", "Вика"], [7.0, 9.0, 9.0])` | открытый | `"Боря"` |
| `winner(["Аня"], [5.0])` | открытый | `"Аня"` |
| `winner(["Аня", "Боря"], [-3.0, -1.0])` | 🔒 **скрытый** | `"Боря"` |
| `average([7.0, 9.0, 8.0])` | открытый | `8.0` |
| `average([7.0, 9.0, 9.0])` | открытый | `8.33` |
| `average([])` | 🔒 **скрытый** | `0.0` |
| `average([2.5])` | 🔒 **скрытый** | `2.5` |
| `ranking(["Аня", "Боря", "Вика"], [7.0, 9.0, 8.0])` | открытый | `["Боря", "Вика", "Аня"]` |
| `ranking(["Аня", "Боря", "Вика"], [7.0, 9.0, 9.0])` | открытый | `["Боря", "Вика", "Аня"]` |
| `ranking(["Аня", "Боря", "Вика", "Гена"], [5.0, 5.0, 5.0, 5.0])` | 🔒 **скрытый** | `["Аня", "Боря", "Вика", "Гена"]` |
| `above_average(["Аня", "Боря", "Вика"], [7.0, 9.0, 8.0])` | открытый | `["Боря"]` |
| `above_average(["Аня", "Боря", "Вика"], [9.0, 9.0, 9.0])` | 🔒 **скрытый** | `[]` |
| `above_average(["Аня", "Боря", "Вика", "Гена"], [1.0, 10.0, 4.0, 5.0])` | 🔒 **скрытый** | `["Боря"]` |

## Что ловит каждый скрытый тест

| Тест | Ошибка, которую он находит |
|---|---|
| `winner` с отрицательными | «лучший» заведён нулём, а не первым участником |
| `average([])` | нет проверки пустого списка — `ZeroDivisionError` |
| `average([2.5])` | округление до сотых потеряно |
| `ranking` при всех равных | неустойчивая сортировка: порядок участников сбился |
| `above_average` при всех равных | нестрогое сравнение `>=` — в ответ попали все |
| `above_average` с разбросом | среднее посчитано заново и неверно, а не вызовом `average` |
