## Типичные ошибки

Оформление вывода студент выбирает сам: подписи, f-строки, подсказки в `input()` и лишние пробелы
тесты не ломают — сравниваются значения. А вот точность входит в ответ: число знаков после точки должно
совпадать с образцом теста. Требование задаётся у практики полем «Точность вывода в тестах» и может быть
переопределено у отдельного теста.

| Задача | Что встречается | Как это выглядит в разборе |
|---|---|---|
| **все** | нет округления: `print(mean)` | пример из условия проходит, а на `1, 2, 2` выводится `1.6666666666666667` вместо `1.7` |
| 3 | `:.1f` вместо `:.2f` | `182.0` вместо `182.00` — засчитывается как другая точность |
| 4 | `:.2f` вместо `:.1f` | `68.00` вместо `68.0` — тест не проходит |
| 1 | `a + b + c / 3` без скобок | на примере из условия `14.333…` вместо `7.0` |
| 1 | `int(input())` | падает на дробном вводе: `ValueError` |
| 2 | `2 * w + h` | периметр не совпадает; площадь при этом верна — тест частично падает |
| 3 | `int` для цены | `ValueError` на `45.50` |
| 4 | `(C + 32) * 9 / 5` | неверно везде, кроме частных совпадений |
| 5 | `total / 3600` вместо `//` | `1.0347…` вместо `1` — значение и точность не совпадают |
| 5 | минуты как `total // 60` | для 3725 выводится `62` вместо `2`: полные часы не вычтены |
| 5 | секунды как `total % 3600` | для 3725 выводится `125` вместо `5` |
| 6 | `print("Студент:", name, ". Группа:", group)` | лишние пробелы вокруг точки: `Анна . Группа` — засчитывается |
| 7 | `number / 100 % 10` вместо `//` | дробные цифры: `2.34` вместо `2` |
| 7 | обратное число без разрядов: сумма цифр в обратном порядке | `10` вместо `4321` |
| 7 | цифры через строку: `s[0]`, `s[::-1]`, `str()` | **тесты проходят** — см. ниже |

### Задача 7 через строку

Условие запрещает переводить число в строку. Решение через `s = input()` и индексы `s[0]` или срез `s[::-1]`
даёт тот же вывод, и автотесты его не отличают. Сервис отмечает в `task07.py` вызовы `str()`, `len()`,
`reversed()`, `join()`, индексы и срезы в разделе «Анализ кода» как запрещённые конструкции, но баллы за тесты
не снимает — вывод ведь верный. Решение за вами: на защите попросите получить цифру сотен числа 9071 через
`//` и `%` — это один из базовых вопросов.

## Совпадения работ

Для этой работы одинаковый код у разных студентов — **норма**: правильное решение задачи в три строки
почти единственное. Сервис исключает из сравнения фрагменты, встречающиеся у трети группы, но этот фильтр
включается, когда сдано хотя бы пять работ. Пока работ меньше, пары помечаются «сдано мало работ».

Поэтому самостоятельность здесь проверяет защита: попросите изменить программу на ходу — например,
выводить два знака после точки или добавить в задачу 5 полные сутки.

## Вопросы для защиты

Видны только преподавателям. В сервисе — вкладка «Вопросы защиты» у практики и форма проверки попытки.
Базовые задайте каждому — два-три на выбор; сложные — если базовые даются легко или есть сомнения в авторстве.

### Базовые

**1. Чем отличаются значения 4 и "4"? Что даст сложение в каждом случае?** · _Типы_

> 4 — число, "4" — строка. Сложение чисел даёт сумму, сложение строк соединяет текст.

**2. Что возвращает input() и зачем нужен float()?** · _Ввод_

> input() всегда возвращает строку; float() превращает числовую запись в число.

**3. Почему print(8 + 4 / 2) даёт 10.0, а не 6.0?** · _Порядок действий_

> Деление выполняется раньше сложения; скобки меняют порядок вычисления.

**4. Что делает формат :.1f — меняет ли он само значение?** · _Вывод_

> Только отображение: печатает один знак после точки, само значение не меняется.

**5. Разберите задачу 5 для 3725 секунд: какие операции дают часы, минуты и секунды?** · _Целочисленное деление_

> 3725 // 3600 = 1 час; 3725 % 3600 = 125; 125 // 60 = 2 минуты; 3725 % 60 = 5 секунд.

**6. Как в задаче 7 получить цифру сотен числа 9071, не переводя число в строку?** · _Цифры числа_

> 9071 // 100 = 90 отбрасывает две последние цифры, 90 % 10 = 0 оставляет последнюю из оставшихся.

**7. Какой результат и тип дадут 7 / 2, 8 / 2 и 7 // 2? Почему 8 / 2 — это 4.0, а не 4?** · _Арифметика_

> 3.5, 4.0 и 3. Оператор / всегда возвращает float, даже при делении нацело; // — целая часть частного.

**8. Чем отличаются операторы /, // и %? Приведите пример, где нужен %.** · _Арифметика_

> / — деление с дробной частью, // — целая часть частного, % — остаток: 17 % 5 = 2. Остаток нужен, например, чтобы проверить чётность или взять последнюю цифру числа.

**9. Что произойдёт в задаче 1, если убрать float() и ввести 4, 7, 10?** · _Ввод_

> input() вернёт строки: сложение склеит их в «4710», а деление строки на 3 вызовет TypeError.

**10. Почему в задаче 3 цену читаем через float, а количество — через int? Что будет, если цену прочитать через int?** · _Типы_

> Цена бывает дробной (45.50), а количество — только целым. int("45.50") вызовет ValueError.

**11. Пользователь ввёл дробное число через запятую: 4,5. Что вернёт input() и что сделает float()?** · _Ввод_

> input() вернёт строку «4,5»; float("4,5") вызовет ValueError — дробную часть в Python отделяют точкой.

**12. Какая ошибка возникнет в выражении "Группа: " + 101 и как её исправить?** · _Типы_

> TypeError: строку нельзя сложить с числом. Нужно str(101) или f-строка: f"Группа: {101}".

**13. Чем f"{x:.1f}" отличается от round(x, 1)?** · _Вывод_

> round возвращает число, форматирование — строку для вывода. round(7, 1) даст 7, а f"{7:.1f}" — «7.0». Для вывода с нужным числом знаков удобнее формат.

**14. В задаче 4 формулу записали как (C + 32) * 9 / 5. Что выведет программа для 0 градусов и почему?** · _Порядок действий_

> 57.6 вместо 32.0: скобки изменили порядок действий. Правильно C * 9 / 5 + 32.

**15. Для сторон 2.5 и 4 вычислите площадь и периметр в уме. Совпадает ли ответ с выводом вашей программы?** · _Проверка решения_

> Площадь 10.0, периметр 13.0. Студент должен уметь получить ответ без запуска программы.

**16. Программа запускается без ошибок. Значит ли это, что она решает задачу? Как вы проверяли свои решения?** · _Проверка решения_

> Нет: корректность проверяют по условию на примерах с заранее вычисленным ответом — включая ноль, отрицательные и дробные значения.

**17. Измените задачу 1 на ваших глазах так, чтобы среднее выводилось с двумя знаками после точки.** · _Практика на защите_

> Меняется только формат: :.2f вместо :.1f. Если студент ищет долго — код писал не он.

**18. Почему в задаче 7 последняя цифра числа не может быть нулём?** · _Цифры числа_

> Иначе число с обратным порядком цифр начиналось бы с нуля: для 1230 получилось бы 321, и одна цифра пропала бы.

**19. Как в задаче 7 собрать число с обратным порядком цифр из четырёх отдельных цифр?** · _Цифры числа_

> Умножить цифры на разряды в обратном порядке: единицы · 1000 + десятки · 100 + сотни · 10 + тысячи.

### Сложные

**20. После a = 5; b = a; a = 7 — чему равно b? Что на самом деле делает присваивание?** · _Переменные_

> b равно 5. Присваивание связывает имя со значением; новое a = 7 перевязывает только имя a.

**21. Почему 0.1 + 0.2 == 0.3 даёт False, а round(2.675, 2) возвращает 2.67?** · _Представление чисел_

> Дробные числа хранятся в двоичном виде приближённо: 0.1 + 0.2 = 0.30000000000000004, а 2.675 на самом деле чуть меньше 2.675. Поэтому для вывода результат округляют форматом.

**22. Измените задачу 5 на ваших глазах: пусть она выводит ещё и полные сутки, а часы — только оставшиеся.** · _Практика на защите_

> days = total // 86400; hours = total % 86400 // 3600; минуты и секунды считаются как раньше.

**23. Строка «CS» занимает 2 байта в UTF-8, и строка «Ж» — тоже 2. Почему?** · _Представление данных_

> Латинские символы кодируются одним байтом, кириллические — двумя: текст хранится как числовые коды.

**24. print("Студент:", name, ".") ставит пробел перед точкой. Какими способами его убрать?** · _Строки_

> f-строкой, склейкой строк через + или параметром sep="" у print.
