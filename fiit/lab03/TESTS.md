# Тесты · ФИИТ · Лабораторная 03

Ровно то, что заведено в сервисе проверки. **Скрытые тесты студенты не видят** — в студенческий репозиторий их не переносить.

Двенадцать запусков одной программы `sensor.py`, 7 баллов на все: тест весит 0,583 балла.
Сравнение — по смыслу: берутся числа вывода, подписи и приглашения `input()` не мешают.
Точность проверяется: у максимума и среднего должен быть ровно один знак после точки.

Ввод: порог, количество записей, затем записи. Вывод: записей, ошибок, превышений, максимум, среднее.

## Что ловит каждый скрытый тест

| Тест | Ошибка, которую он находит |
|---|---|
| ошибка последней записью | цикл прочитал не все записи |
| отрицательные показания | максимум начат нулём |
| дробный порог | сравнение целых вместо дробных, `>=` вместо `>` |
| корректное показание одно | среднее поделено на все записи, а не на корректные |
| много записей | накопление суммы или счётчика превышений сбивается на длинном входе |
| нулевой порог и нулевые показания | `0` принят за «пусто»: показание 0 пропущено как ошибка |
