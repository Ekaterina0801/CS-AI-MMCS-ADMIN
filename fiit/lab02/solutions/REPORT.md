## Состояния файла

До `git add` команда `git status` показывает файл в разделе «Changes not staged for commit»:
изменение есть в рабочей копии, но в индекс не попало. После `git add lab02/NOTES.md`
тот же файл переходит в «Changes to be committed» — он подготовлен к сохранению.
После `git commit` рабочая копия чистая, и `git status` сообщает «nothing to commit».

`git diff` сравнивает рабочую копию с индексом — то есть показывает изменения, которые
ещё не подготовлены. `git diff --staged` сравнивает индекс с последним коммитом и показывает
ровно то, что уйдёт в следующий коммит. После `add` первая команда пуста, а вторая
показывает моё изменение: это и есть наглядная разница между двумя состояниями.
